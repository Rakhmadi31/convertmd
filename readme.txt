Aplikasi Konversi Dokumen Markdown ↔️ DOCX/DOC/PDF

Deskripsi:
- Aplikasi ini adalah antarmuka Streamlit untuk mengonversi file Markdown (.md) ke file .docx, .doc, atau .pdf.
- Aplikasi juga mendukung konversi file .docx, .doc, atau .pdf kembali ke Markdown (.md).
- Konversi dilakukan menggunakan Pandoc sebagai mesin standar untuk kompatibilitas dokumen yang baik.

Fitur Utama:
- Unggah file .md, .docx, .doc, atau .pdf
- Pilih format target konversi yang sesuai
- Unduh hasil konversi secara langsung

Persyaratan:
- Python 3.x
- Streamlit terpasang
- Pandoc terinstal di sistem

Cara Menjalankan:
1. Pastikan environment Python Anda aktif.
2. Jalankan: streamlit run konvertmd.py
3. Buka URL yang ditampilkan di browser.
4. Unggah file dan pilih format konversi.

Catatan:
- Pastikan Pandoc terpasang secara native di sistem Anda, bukan hanya paket Python.
- Untuk konversi PDF mungkin diperlukan dependensi tambahan di sistem operasi.

Document Conversion Application Markdown ↔️ DOCX/DOC/PDF

Description:
- This app is a Streamlit interface for converting Markdown (.md) files to .docx, .doc, or .pdf.
- It also supports converting .docx, .doc, or .pdf files back to Markdown (.md).
- Conversion uses Pandoc as the engine to ensure good document compatibility.

Key Features:
- Upload .md, .docx, .doc, or .pdf files
- Select the desired output format
- Download converted results directly

Requirements:
- Python 3.x
- Streamlit installed
- Pandoc installed on your system

How to Run:
1. Activate your Python environment.
2. Run: streamlit run konvertmd.py
3. Open the URL shown in your browser.
4. Upload a file and choose the conversion format.

Notes:
- Make sure Pandoc is installed natively on the system, not only via Python package.
- PDF conversion may require additional OS-level dependencies.
